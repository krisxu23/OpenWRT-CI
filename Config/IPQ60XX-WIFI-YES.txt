# 一、满血 NSS 硬件加速（IPQ6000 芯片级加速）
# 来源：[B] nss.config + [C] ipq60xx-6.12-wifi.config
# 注意：NSS 固件版本用 11.4 —— 与 VIKINGYFY/immortalwrt 源码匹配（ZqinKing 同源验证）。
#       laipeng668 的 12.5 版本只适用于他自编译的 immortalwrt openwrt-25.12 分支，
#       直接抄 12.5 会在 VIKINGYFY/immortalwrt 上无效，故不用。
# ============================================================
# ★ 重要结论（依据 VIKINGYFY/immortalwrt 源码实测）：
#   VIKINGYFY/immortalwrt 的 qualcommax 平台【已内置满血 NSS】——
#   target/linux/qualcommax/Makefile 的 DEFAULT_PACKAGES 已默认带入：
#     kmod-qca-nss-drv + kmod-qca-nss-ecm + kmod-qca-nss-dp + kmod-qca-ssdk
#     + kmod-qca-nss-crypto + 18 个 drv 子模块（igs/l2tpv2/lag-mgr/map-t/
#     pppoe/pptp/qdisc/vxlanmgr/... 等）
#   config-6.18 也已内置 CONFIG_SKB_RECYCLER=y（NSS 内核配套）。
#   ⇒ 因此【无需】在 .config 里写 kmod-qca-nss-drv-* / CONFIG_NSS_DRV_* /
#     CONFIG_KERNEL_SKB_RECYCLER，它们默认就已编译进固件。

# 只需保留 NSS 固件版本选择（安全保险：确保引擎固件用 11.4 版本；
# 若该选项在当前源码不存在，make defconfig 会自动忽略该行，无副作用）
CONFIG_NSS_FIRMWARE_VERSION_11_4=y
# CONFIG_NSS_FIRMWARE_VERSION_12_5 is not set  (12.5 仅适用于 laipeng668 自编译分支，勿用)

# 说明：本机硬改 1G 内存，ath11k 走 DTS 完整内存模式（Settings.sh 已处理
#       qcom,ath11k-fw-memory-mode = <0>），因此【不要】再开
#       CONFIG_ATH11K_MEM_PROFILE_512M（那是 512M 原厂内存的省内存模式）。
#       CONFIG_IPQ_MEM_PROFILE_* 同理由 DTS/CDT 决定，不再显式指定。
